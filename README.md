# FLX4 DJ 入門

Pioneer DJ DDJ-FLX4 で DJ をはじめる人のための学習サイトです。HTML/CSS/JavaScript だけで動きます。

- **DJ 入門コース**（`index.html`、`learn/`）：前提知識からはじめてのミックス、rekordbox の使いこなしまで、24 レッスンを順番に学ぶ。ソフトは rekordbox 7（Mac/Windows）が前提
- **本体マニュアル**（`manual/`）：FLX4 の図をクリックして、どのボタンで何ができるかを調べる

## DJ 入門コース

| 部 | レッスン |
|---|---|
| 1. DJ の前提知識 | DJ はなにをしているのか／拍・小節・BPM／曲の構成とフレーズ／音の基本：周波数・EQ・音量／キーと曲の相性／曲の入手とファイル形式 |
| 2. 準備する | 機材をつないでソフトを準備する／FLX4 の各部とホームポジション／rekordbox の画面の見かた／rekordbox の設定を整える／曲を取り込んで解析する／CUE を打つ／曲を整理して探す |
| 3. つなぐ | ヘッドホンで次の曲を聴く／テンポを合わせる（ビートマッチ）／フレーズの頭でつなぐ／はじめてのミックス |
| 4. 表現を広げる | ループとビートジャンプ／エフェクト：CFX と BEAT FX／パッドを使ったテクニック／rekordbox の演奏機能／選曲とセットの組み立て／クラブの機材で DJ する／練習のしかたと次のステップ |

付録として、用語集（`learn/glossary.html`）と困ったとき（`learn/trouble.html`）があります。

### 特徴

- **音を鳴らして確かめる練習ツール**：ビートカウンター、BPM タップ、フレーズの頭を当てるゲーム、1 チャンネルのミキサー、CUE とホットキューの練習、ビートマッチの練習、2 デッキのミックス練習（手順を自動で判定するミッションつき）、Camelot ホイール。練習用の曲はブラウザの中で合成しているので、音源ファイルは使っていません
- **ソフトの切り替え**：rekordbox（Mac/Windows・iOS/Android）と Serato DJ Lite で違う操作は、切り替えて読める（本体マニュアルと設定を共有）
- **本体マニュアルへのリンク**：本文のボタン名をクリックすると、本体マニュアルでその部品が選ばれる
- **用語のツールチップ**：点線の付いた用語にマウスを重ねると説明が出る
- **進み具合の記録**：レッスンの完了をブラウザに保存し、トップページに進み具合を表示する

## 本体マニュアル

- 本体の図をクリックすると、「押す」「回す」「SHIFT + 押す」などの操作ごとの説明を表示
- SHIFT（画面のボタン、またはキーボードの Shift キー）、パッドモードごとの割り当て、操作ガイド、一覧と検索
- 選んだ部品は URL（`manual/index.html#load/1/` など）に反映される。以前の URL（`/#load/1/`）は自動で転送する
- `?scale=1` を付けると本体図を等倍（931×516px）で表示する

## ファイル構成

```
ddj-flx4/
├── index.html            # トップページ（コースの学習マップ）
├── learn/                # レッスン、用語集、困ったとき
├── manual/index.html     # 本体マニュアル
├── css/
│   ├── site.css          # コースの共通スタイル
│   ├── widgets.css       # 練習ツールのスタイル
│   ├── styles.css        # 本体図のスタイル
│   └── manual.css        # 本体マニュアルの画面のスタイル
├── js/
│   ├── course.js         # コースの構成（レッスンの順番とタイトル）
│   ├── glossary.js       # 用語集のデータ
│   ├── site.js           # ヘッダー、コース一覧、目次、クイズ、ツールチップなどの共通処理
│   ├── audio.js          # 練習用の音のエンジン（曲の合成、デッキ、ミキサー）
│   ├── widgets.js        # 練習ツール
│   ├── manual-data.js    # 本体マニュアルのデータ（各部の機能、パッドモード、操作ガイド）
│   └── script.js         # 本体マニュアルの画面の動作
└── docs/
    └── .private/         # 取扱説明書 PDF など（Git 管理外）
```

レッスンは `learn/<id>.html` に本文だけを書き、ヘッダーやコース一覧などは `js/site.js` が差し込みます。練習ツールは `<div data-widget="mixer" data-mission="first-mix"></div>` のように書くと組み立てられます（設定は `js/widgets.js` の先頭を参照）。

## 使用方法

ローカルサーバーを立てて開いてください。

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

GitHub Pages では `main` ブランチのルートを公開しています（`https://fallere246.github.io/ddj-flx4/`）。

## 内容について

本体の操作は DDJ-FLX4 取扱説明書（DRJ1092-A）、rekordbox の操作は rekordbox 7（ver. 7.0.0）操作説明書をもとに要約したものです。正確な仕様は公式の取扱説明書と、rekordbox・Serato のマニュアルを確認してください。このサイトは個人が作った非公式のもので、Pioneer DJ、AlphaTheta、rekordbox、Serato とは関係ありません。
