音の基本：周波数・EQ・音量

2 曲を混ぜるときに DJ がいちばん多く触るのは、EQ と音量のつまみです。このレッスンでは音の高さを表す周波数と、帯域ごとに音量を調整する EQ、3 段階ある音量のつまみの役割、音割れを防ぐ音量の決め方を、音を聴きながら学びます。

このレッスンでできるようになること

  • 低音・中音・高音にどんな楽器がいるかを説明できる
  • EQ で帯域を下げたとき、何が変わるかを聴き分けられる
  • TRIM・チャンネルフェーダー・MASTER LEVEL の役割の違いが分かる
  • 音割れさせずに、曲の音量をそろえる手順が分かる

音の高さ：周波数

音は空気の振動です。1 秒間に振動する回数を周波数といい、単位は Hz（ヘルツ）です。周波数が小さいほど低い音、大きいほど高い音になります。

人間の耳に聞こえるのは、およそ 20 Hz から 20 kHz（20,000 Hz）の範囲といわれています。年齢や個人によって差があり、特に高い音は年齢とともに聞こえにくくなります。

DJ の EQ はこの範囲を低音・中音・高音の 3 つに分けて扱います。それぞれの帯域にいる音は、おおよそ次のとおりです。

帯域おおよその範囲どんな音がいるか
低音（LOW）数十 Hz〜数百 Hzキック、ベースライン。体に響く「ドン」「ブーン」
中音（MID）数百 Hz〜数 kHzボーカル、コード、メロディー、スネアの胴鳴り。曲の「中身」
高音（HI）数 kHz 以上ハイハット、シンバル。「シャッ」「チッ」

境目の周波数は機材やソフトによって違い、数字は目安です。「どの楽器が、どの帯域にいるか」を耳で分かるようになることが大切です。

EQ：帯域ごとの音量つまみ

EQ（イコライザー）は、低音・中音・高音の音量を、別々に調整するつまみです。FLX4 では、各チャンネルに HI / MID / LOW の 3 つがあります。

  • 中央：何も変えない、曲そのままの音
  • 左に回す：その帯域を下げる。大きく下げて、ほぼ聞こえなくすることをカットという
  • 右に回す：その帯域を上げる。上げすぎると音が割れやすくなるので、少しだけにする

DJ が EQ を使う理由は、2 曲を重ねたときに、同じ帯域の音がぶつかって濁るのを防ぐためです。特に、2 曲のキックとベースが重なると低音がぼやけてしまうので、片方の LOW を下げて重ねます。これは「はじめてのミックス」で使う、いちばん基本のテクニックです。

EQ を下げて何が消えるか聴く

下のツールは 1 つのチャンネルだけを再現した練習台です。再生して、HI・MID・LOW を 1 つずつ下げてみてください。どの楽器の音が消えるか、そして右側の「低音・中音・高音」の表示がどう変わるかを確かめます。

  1. 再生を押す（ドロップから始まるので、すべての楽器が鳴っている）
  2. LOW を左いっぱいに回す。キックとベースが消え、軽い音になる。右側の「低音」の表示が小さくなる
  3. LOW を中央に戻し、MID を左いっぱいにする。メロディーやコードが引っ込む
  4. MID を戻し、HI を左いっぱいにする。ハイハットなどの細かい音が消え、こもった音になる
ダブルクリックで元に戻る

ツールのつまみはダブルクリック（スマホではダブルタップ）で元の位置に戻ります。実機の FLX4 でも、EQ は「中央に戻してから始める」のが基本です。

フィルター（CFX）との違い

EQ は帯域を 1 つずつ個別に上げ下げするつまみです。CFX は 1 つのつまみで音色を変えるエフェクトです。フィルターとして使うと、中央で効果なし、左に回すとこもった音、右に回すと低音が抜けた音になります（どの効果がかかるかはソフトと設定で変わります）。使い方は「エフェクト：CFX と BEAT FX」で学びます。

曲の LOW を左いっぱいにすると、いちばん大きく変わるのはどれ？

  • ボーカルが聞こえなくなる
  • キックとベースが弱くなり、軽い音になる
  • ハイハットが聞こえなくなる

LOW は低音の帯域です。キックやベースは低音にいるので、LOW を下げるとそれらが引っ込みます。ボーカルは中音、ハイハットは高音の担当です。

音量の 3 段階

DJ 機材には音量を変えるつまみが 3 つあります。名前は似ていますが、役割が違います。音の流れの上で、順に並んでいます。

順番つまみ役割
1TRIM曲ごとの音量の差をそろえる。曲を入れたら、まずここで合わせる
2チャンネルフェーダーミックスの中で、その曲を出し入れする。DJ がいちばん動かす
3MASTER LEVELスピーカーに出る全体の音量。場の大きさに合わせる

曲ごとに録音された音量はばらばらです。静かにつくられた曲もあれば、とても大きな曲もあります。TRIM で曲の音量をそろえておけば、フェーダーを動かしたときに、「次の曲だけ急に大きい」ということが起きません。そろえたあとは、TRIM を動かさず、フェーダーで出し入れします。

MASTER LEVEL は会場やスピーカーに合わせて決める全体の音量です。曲ごとの調整には使いません。

音量を見る：レベルインジケーターと音割れ

FLX4 のミキサーには、各チャンネルの音量を光で表示するチャンネルレベルインジケーターがあります。このインジケーターはチャンネルフェーダーを通る前の音量を表示します。つまり、フェーダーを下げても表示は変わらず、TRIM と EQ の結果が見えます。

デジタルの音には、扱える大きさの上限があります。上限を超えると、波の頭が切れて、音が歪みます。これを音割れ（クリップ）といい、耳に不快で、スピーカーにも負担がかかります。下げれば直るので、TRIM で音量を調整します。

EQ の上げすぎにも注意

EQ を右に上げると、その帯域の音が大きくなり、音割れしやすくなります。基本は「上げる」より「下げる」で調整します。

TRIM の合わせ方

取扱説明書に沿った、再生を始める前の各つまみの位置は次のとおりです。

  • TRIM：左いっぱい
  • EQ（HI / MID / LOW）：中央
  • CFX：中央
  • チャンネルフェーダー：手前（いちばん下）
  • MASTER LEVEL：左いっぱい
  • クロスフェーダー：中央

この状態から、曲を再生して次の手順で合わせます。

  1. チャンネルフェーダーを上げ、スピーカーの音が出る状態にする（MASTER LEVEL も少しずつ上げる）
  2. 曲を再生しながら、TRIM を少しずつ右に回す
  3. チャンネルレベルインジケーターを見て、いちばん上のオレンジ色が、ピーク（音の大きい瞬間）で点くくらいで止める

オレンジ色が点きっぱなしになるのは大きすぎです。まったく点かないのは、小さめです。曲のいちばん音が大きい部分（ドロップなど）で確かめるのがコツです。

練習：TRIM を合わせる

下のツールは TRIM が左いっぱいの状態で始まります。練習曲 Night Signal は Sunrise Drive より少し大きく録音されています。TRIM を右に回して、メーターの様子とメッセージを見ながら、音割れせず、ちょうどよい音量に合わせてみましょう。

音が割れない範囲で、曲が小さすぎず、メーターのオレンジがときどき点くところが目安です。曲によって最適な位置が違うことを覚えておいてください。Night Signal は大きい曲なので、Sunrise Drive より TRIM を少し低めにして、2 曲の音量をそろえます。

チャンネルレベルインジケーターの、いちばん上のオレンジ色が点きっぱなしです。まず何をする？

  • MASTER LEVEL を上げる
  • チャンネルフェーダーを上げる
  • TRIM を少し左に回して下げる

インジケーターはチャンネルフェーダーの手前の音量を表しています。音量が大きすぎるときは、TRIM で下げます。フェーダーや MASTER LEVEL では、インジケーターの表示は変わりません。

dB（デシベル）

音量を表す単位に、dB（デシベル）があります。dB は 2 つの音量の比を表す単位です。数字が大きいほど大きい音で、+3 dB のようなわずかな差でも、聴いて分かります。

デジタルの音では、上限を 0 dB として、それより小さい音をマイナスの数で表します。-10 dB、-20 dB のように、数字が小さい（マイナスが大きい）ほど小さい音です。ソフトのメーターに dB の目盛りが出ていたら、0 dB に近づくほど上限に近い、と読んでください。

DJ が dB の細かい計算をすることはありません。「数 dB の違いでも聴感は変わる」「0 dB を超えると割れる」の 2 つを知っていれば十分です。

耳を守る

DJ にとって耳は、仕事の道具です。大きな音で傷んだ耳は元に戻りにくいといわれています。次のことを守りましょう。

  • 大きな音を長時間聴かない。ヘッドホンの音量は、少し小さめを基本にする
  • ヘッドホンの音量（HEADPHONES LEVEL）は、左いっぱいから、少しずつ上げる
  • 練習中もときどき休憩して耳を休める
  • クラブなど大きな音の場所に行くときは、耳栓を使う。音楽用に、音質をあまり変えずに音量を下げる耳栓もある
耳が痛い・鳴るときは

耳鳴りがしたり、音がこもって聞こえたりしたら、すぐに大きな音から離れて休みましょう。症状が続くときは、医療機関に相談してください。

TRIM とチャンネルフェーダーの使い分けとして、正しいのはどれ？

  • TRIM でミックス中に曲を出し入れし、フェーダーで曲ごとの音量差をそろえる
  • TRIM で曲ごとの音量差をそろえ、フェーダーでミックス中に曲を出し入れする
  • どちらも同じ役割なので、好きなほうを使えばよい

TRIM は入り口の音量調整で、曲ごとにそろえておくものです。フェーダーはミックスの中での出し入れ用で、TRIM をそろえておけば、フェーダーの動きが予想しやすくなります。

まとめ

  • 音の高さは周波数（Hz）。DJ の EQ は低音・中音・高音の 3 つに分けて扱う
  • 低音はキックとベース、中音はボーカルやコード、高音はハイハットやシンバル
  • EQ は中央でそのまま。左に回すと下げる（カット）、右は上げすぎない
  • 音量は TRIM（曲ごとの差をそろえる）→ チャンネルフェーダー（出し入れ）→ MASTER LEVEL（全体）の 3 段階
  • TRIM は左いっぱいから上げ、インジケーターのオレンジがピークで点くくらいに合わせる
  • 耳は大切に。大きな音を長く聴かない
