クラブの機材で DJ する

クラブやバーには、パソコンではなくCDJ などの DJ プレーヤーとミキサーが置いてあることがよくあります。そこで自分の曲をかけるには、rekordbox で準備した曲を USB メモリーなどに書き出して持っていきます。このレッスンではその書き出しの手順と、本番前の確認を説明します。画面の説明は rekordbox（Mac/Windows）のものです。

このレッスンでできるようになること

  • EXPORT モードと PERFORMANCE モードの違いを説明できる
  • USB メモリーに曲とプレイリストを書き出せる
  • 書き出しで一緒に持っていける情報と、持っていけない情報を知っている
  • 本番前の確認項目を挙げられる

なぜ書き出しが必要なのか

家では FLX4 をパソコンにつないで rekordbox を動かします。曲のデータもパソコンの中にあります。ところがクラブのブースには、たいていパソコンはありません。置いてあるのは DJ プレーヤー（CDJ など）と DJ ミキサーです。プレーヤーには USB メモリーなどを挿す差し込み口があり、そこから曲を読み込みます。

そこで、rekordbox のコレクションにある曲とプレイリストを、USB メモリーに書き出します。このとき、家で準備した次の情報も一緒に書き出されます。

  • 曲の BPM とビートグリッド（解析の結果）
  • CUE やループの位置、ホットキュー
  • プレイリストの中身と順番

解析や CUE 打ちを家で済ませておけば、ブースでは選曲とミックスに集中できます。これがここまでのレッスンで準備を丁寧にやってきた理由の 1 つでもあります。

EXPORT モードとは

rekordbox には、画面の左上で切り替える動作モードがいくつかあります。このレッスンで使うのは EXPORT です。FLX4 で演奏するときは、これまで使ってきたPERFORMANCE モードです。

PERFORMANCE モードEXPORT モード
目的rekordbox 対応の DJ 機器をつないで、パソコンで演奏する曲を準備して、DJ プレーヤーに渡す（USB メモリーへの書き出し、LAN での接続）
音を出す場所rekordbox と FLX4クラブの DJ プレーヤーとミキサー
パソコンの役割演奏の中心準備と、ブースの機材との橋渡し

EXPORT モードでは画面のプレーヤーパネルでも曲を再生できます。1 PLAYER、2 PLAYER、DUAL PLAYER など、レイアウトも選べます。ここで CUE やループ、ホットキューを設定したり、ビートグリッドを直したり、2 曲を重ねて相性を確かめたりできます。つまり EXPORT モードは「ブースに持っていく曲の下ごしらえをする場所」です。

FLX4 では使えない機能もある

FLX4 を Hardware Unlock でつないでも、表示は Free プランのままです。rekordbox.com の説明では、Free プランでも曲の管理、USB への書き出し、LINK EXPORT、録音などができます。ただし、機能ごとの制限はプランや接続機器で変わるので、書き出しを試して確かめておきましょう。

USB メモリーに書き出す

使える記録媒体とファイルシステム

記録媒体はデータの整理のしかたが決まっています。この決まりをファイルシステムといいます。rekordbox が書き込める組み合わせは次のとおりです。

記録媒体FAT16FAT32exFATHFS+NTFS
USB ストレージデバイス（フラッシュメモリー、ハードディスク）使える使える使える使える（Mac で利用）使えない
SD メモリーカード使える使える使える使えない使えない
  • NTFS と、HFS（HFS+ ではない古い形式）には書き込めない。NTFS などの非対応の形式のデバイスは、rekordbox の画面に非対応を示す表示が出る
  • 操作説明書は、Windows では FAT32、Mac では FAT32 か HFS+ のデバイスを使うよう案内している
  • exFAT が使えるかどうかは、ブースの DJ 機器側で決まる。操作説明書は exFAT に対応する DJ 機器を rekordbox.com の FAQ で確認するよう案内している
  • DJ 機器が対応している媒体（USB だけか、SD カードも使えるか）は、機器ごとに違う。各機器の取扱説明書で確認する
新しいメモリーを買う前に確かめる

大容量の USB メモリーは買ったままだと exFAT や NTFS になっていることがあります。初期化（フォーマット）すると中のデータは消えるので、先にバックアップを取ってから行ってください。迷ったら、どの DJ 機器にも通りやすい FAT32 が無難です。ただし FAT32 には 1 ファイル 4 GB までという一般的な制限があります。長い WAV ファイルなどは注意してください。

ストリーミングの曲は書き出せない

Apple Music などのストリーミングの曲は、USB メモリーへの書き出しも、LINK EXPORT での再生もできません。クラブの機材で使いたい曲はファイルで購入して rekordbox に入れておきます（「曲の入手とファイル形式」）。

曲とプレイリストを書き出す

ここからは、操作説明書の流れに沿った手順です。ボタンの絵や細かい表示は、rekordbox のバージョンで変わることがあります。

  1. rekordbox の画面左上で EXPORT を選ぶ。
  2. 書き出したい曲とプレイリストが、コレクションにそろっていて、解析と CUE 打ちが終わっていることを確かめる。
  3. パソコンに USB メモリーを挿す。ブラウザパネルのメディアブラウザにある デバイス に、USB メモリーが表示される。表示されないときは、操作説明書の「コンピューターに USB ストレージデバイスを接続する」の項を見る。
  4. 必要なら、デバイスの設定を確認する。DJ プレーヤーの画面に出るデバイス名、背景色、波形の色、曲を並べる順番などを、ここで決められる。
  5. デバイス の中の USB メモリーを開き、プレイリスト フォルダも開く。
  6. 書き出したいプレイリストを、USB メモリーのところにドラッグ＆ドロップする。画面の一番下に進み具合のバーが出て、プレイリストの曲とその付随情報が転送される。
  7. 転送が終わったら、USB メモリーの横の取り外しの操作をしてから、USB メモリーを抜く。

曲を 1 曲ずつ、コレクションから USB メモリーへドラッグして転送することもできます。ただし、本番で使う曲はプレイリストにまとめておくほうが、プレーヤー側で探しやすくなります。

抜くときは、必ず取り外しの操作をする

操作説明書によると、一部の DJ プレーヤーでは、曲を転送するだけでなく、USB メモリーの中に専用のライブラリー（曲やプレイリストのデータベース）が必要です。この専用ライブラリーはデバイスを取り外すときに作られます。転送中のデバイスは取り外せません。いきなり引き抜かず、転送の終了を待って、取り外しの操作を行ってください。

書き出しのあと、パソコンに戻せるもの

書き出しは片道ではありません。クラブのプレーヤーで演奏した USB メモリーをパソコンにつなぐと、次のことができます。

  • 演奏履歴の取り込み：プレーヤーで再生した曲の履歴が、rekordbox の 演奏履歴 に入る。環境設定の DJ システムカテゴリー、デバイスタブにある、演奏履歴を自動で取り込む項目にチェックが入っていれば自動で、そうでなければ手動で取り込む
  • トラック情報の更新：USB メモリーを右クリックして コレクションを更新 を選ぶと、プレーヤー側で変えた CUE・ループ・ホットキュー・ビートグリッド・カラー・評価・コメントが、rekordbox に反映される。反映される内容は DJ プレーヤーによって異なる
  • 別のパソコンで書き出したプレイリストの取り込み：デバイス の中で右クリックして、プレイリストのインポートを選ぶ

本番のあと、曲順の記録や、その場で気づいた直しを持ち帰れるので、次のセットの準備に役立ちます。

Windows のパソコンで、新しく買った USB メモリーを rekordbox で書き出し先にしたいと思います。ファイルシステムが NTFS になっていました。どうすればよい？

  • そのまま書き出す。NTFS は問題なく使える
  • バックアップを取ってから、FAT32 などに初期化する
  • SD メモリーカードに入れ替えれば NTFS でも使える

NTFS は USB ストレージデバイスにも SD メモリーカードにも、rekordbox からは書き込めません。Windows では FAT32 が案内されています。初期化すると中身が消えるので、先にバックアップを取ります。

書き出しで持っていける情報

操作説明書で確認できる範囲で、まとめます。

情報メモ
BPM とビートグリッドプレーヤーの CUE やループのクオンタイズ、複数のプレーヤー間の SYNC に使われる
CUE（メモリーキュー）1 曲に保存できるのは、ループと合わせて最大 10 個。DJ プレーヤーで呼び出せる
ループメモリーキューと同じく保存して持っていける。保存したループを「アクティブループ」にしておくと、対応するプレーヤーで再生したとき、その場所で自動でループする
ホットキュー1 曲に 8 個（A〜H）。ただしプレーヤーによって、使える数が違う
プレイリストプレーヤーによって、名前やフォルダの階層に制限がある
キューの色・コメントプレーヤーによっては、設定した色やコメントを表示できない
ホットキューバンクリスト別々の曲のホットキューを 8 つまで組み合わせて登録できる機能。一部のプレーヤーではロードできない
プレーヤーごとの違いは取扱説明書で

操作説明書はプレーヤーでの具体的な操作を「各 DJ 機器の取扱説明書を見てください」と案内しています。機種によって、ホットキューの数、表示できる情報、読めるファイル形式が違うためです。自分がよく行く店のプレーヤーの機種が分かれば、その取扱説明書を事前に読んでおくと安心です。

本番前のチェックリスト

ブースでは機材を借りて、短い時間で準備します。家でできる確認は家で済ませておきましょう。

  • 書き出したあと、実際に読み込めるか確かめる：できれば同じ系統のプレーヤーで、曲が表示されること、再生できること、CUE やホットキューが出ることを確かめる。お店や友人のスタジオ、練習用に借りられる機材などを探す
  • ファイルシステムを確認する：使う USB メモリーの形式が行く店のプレーヤーに対応しているか。exFAT を使うなら、機器の対応を先に確認する
  • 予備の USB メモリーを用意する：同じ内容を書き出したものを 2 つ持つ。USB メモリーは抜き差しの途中で壊れたり、認識されなかったりすることがある
  • 曲の数と容量を確かめる：全部入れるより、そのセットに必要な曲に絞る。曲が多いと、プレーヤー側で探すのに時間がかかる
  • ファイル形式を確認する：プレーヤーが読み込めるファイル形式は、機種ごとに決まっている。取扱説明書で確認する
  • 曲の準備を済ませておく：解析の結果、グリッドのずれ、BPM が 2 倍や半分になっていないか、CUE の位置。書き出してから直すと、また書き出しが必要になる
  • パソコン側のバックアップ：書き出す前に、コレクションとファイルのバックアップも取っておく。操作説明書も、登録した情報が消えても責任を負えないので、別に保管するよう案内している

本番前の準備として、いちばん優先度が高いのはどれ？

  • USB メモリーに、持っている曲を全部入れる
  • 書き出したあと、プレーヤーで読み込めて再生できるか確かめ、予備の USB メモリーも用意する
  • ブースに着いてから、プレーヤーで CUE を打ち直す

本番に間に合うかどうかを分けるのは、読み込めることと再生できることです。予備があれば、1 つが認識されなくても続けられます。CUE は家のうちに rekordbox で打っておきます。

PRO DJ LINK：パソコンとプレーヤーをつなぐ

USB メモリーを使わずに、パソコンと DJ プレーヤーをLAN ケーブルまたは無線 LAN でつなぐ方法もあります。これを PRO DJ LINK といいます。操作説明書では書き出す方法と LAN でつなぐ方法を、次のように区別しています。

方法つなぎ方特徴
USB EXPORTUSB メモリーなどに書き出して、プレーヤーに挿すブースにパソコンを持ち込まない
LINK EXPORTパソコンとプレーヤーを LAN でつなぐ書き出さなくても、rekordbox の曲をプレーヤーに直接ロードできる。rekordbox の検索機能も使える

LINK EXPORT の流れはおおまかに次のとおりです。

  1. パソコンと DJ 機器を、LAN ケーブルか無線 LAN でつなぐ。
  2. 機器が見つかると、ブラウザパネルの左下に LINK ボタンが出る。これを押して通信を始める。
  3. 下にリンクステータスパネルが出て、つながっている機器が表示される。曲をトラックリストから、そのプレーヤーの表示までドラッグすると、プレーヤーにロードされる。
  • スイッチングハブや PRO DJ LINK 対応の DJ ミキサーを間に入れると、複数のプレーヤーで音楽ファイルやデータを共有できる。つなげるプレーヤーの台数は、機器によって違う
  • PRO DJ LINK につなげるコンピューターは 2 台まで
  • PRO DJ LINK 対応の DJ ミキサーとつなぐと、ミキサーのヘッドホンで rekordbox の曲を試聴できる（環境設定の DJ システムカテゴリーでの設定が必要）
  • PRO DJ LINK でつないでいる間は、rekordbox でのビートグリッドの調整はできない
  • セキュリティソフトや OS の設定が通信を止めて、つながらないことがある
ブースにパソコンを置けるとは限らない

お店によっては、ブースにパソコンを置けなかったり、LAN の接続が使えなかったりします。LAN の接続方法も機器ごとに違います。まずは USB メモリーでの書き出しを確実にできるようにしておき、LAN は必要になったときに、機器の取扱説明書とあわせて調べましょう。

FLX4 とクラブの機材の違い

FLX4 で練習した基本はクラブの機材でもそのまま通用します。デッキで曲を選び、ミキサーで EQ とフェーダーを動かして、つなぐ。やることは同じです。ただし、機材によって違うところもあります。ここは一般的な話なので、細かい動きは使う機材の取扱説明書で確認してください。

  • 配置：FLX4 は、デッキ 2 つとミキサーが 1 台にまとまっている。クラブではプレーヤー 2 台の間に、独立したミキサーが置かれることが多い。ボタンの位置が違うので、最初は探す時間がかかる
  • 曲の読み込み：FLX4 ではパソコンの画面で曲を選んでロードする。プレーヤーでは本体のディスプレイとセレクターで、USB メモリーの中から選んで読み込む
  • SYNC とクオンタイズ：SYNC やクオンタイズの機能を持つプレーヤーは多いが、動きや使える条件は機種ごとに違う。ビートグリッドが正しいことが前提になる点は同じ
  • 機能の数：ホットキューの数、ループ、エフェクトの種類などは、機種で違う
  • 音量の調整：ミキサーの TRIM・EQ・チャンネルフェーダーの基本は同じ。ただしブースの音響設備は店ごとに違うので、音量はその場で耳で確かめる

お店のスタッフに頼んで、営業前に機材を触らせてもらえることもあります。その場合は、事前に聞いてみましょう。

PRO DJ LINK の LINK EXPORT の説明として、正しいのはどれ？

  • USB メモリーに書き出したあと、パソコンを接続しないで使う
  • LAN でつなぐと、パソコンの画面でビートグリッドを自由に直せる
  • パソコンとプレーヤーを LAN でつなぎ、書き出さずに rekordbox の曲をプレーヤーにロードできる

パソコンを持ち込まずに USB メモリーだけで使う方法は USB EXPORT です。また、PRO DJ LINK で接続している間は、rekordbox でのビートグリッドの調整はできません。

まとめ

  • クラブにはパソコンがないことが多い。rekordbox で準備した曲を、USB メモリーなどに書き出して持っていく
  • 書き出しは EXPORT モードで行う。デバイスにプレイリストをドラッグし、転送が終わったら取り外しの操作をしてから抜く
  • USB メモリーのファイルシステムは FAT32 が無難。NTFS には書き込めない。exFAT はブースの機器の対応を確認する
  • BPM・ビートグリッド・CUE・ループ・ホットキューも一緒に持っていけるが、使える内容はプレーヤーで違う
  • 本番前に、読み込めるかを確かめ、予備の USB メモリーを用意する
  • PRO DJ LINK ではパソコンとプレーヤーを LAN でつなぐ。機材ごとの違いは取扱説明書で確認する
