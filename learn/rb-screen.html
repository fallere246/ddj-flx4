rekordbox の画面の見かた

FLX4 を rekordbox につなぐと、パソコンの画面にもデッキや波形が表示されます。画面は情報が多く、最初はどこを見ればよいか迷います。このレッスンでは画面にあるものを場所ごとに分け、「何が分かるか」「いつ見るか」を整理します。説明は rekordbox 7 の Mac/Windows 版の画面で行います。

このレッスンでできるようになること

  • EXPORT モードと PERFORMANCE モードの違いを説明でき、PERFORMANCE モードに切り替えられる
  • 画面のどこに、デッキの情報・波形・ミキサー・ブラウザーがあるか分かる
  • デッキの BPM・キー・残り時間・テンポの値などの表示を読み取れる
  • FLX4 でトラックを選んで、デッキに読み込む流れが分かる

2 つのモード：EXPORT と PERFORMANCE

rekordbox は、曲の管理と DJ プレイの両方ができるソフトです。使い方に合わせて、画面左上で 2 つのモードを切り替えます。

モード何をするモードかFLX4 との関係
EXPORT曲を USB メモリーなどに書き出して、クラブにあるような DJ プレーヤー（CDJ / XDJ シリーズなど）で DJ をするための準備をする。DJ 機器をネットワークでつなぐ使い方もここで行うFLX4 での DJ には使わない
PERFORMANCErekordbox そのものを DJ ソフトとして使う。DJ コントローラーなどをつなぎ、パソコンの中の曲を再生してミックスするFLX4 で DJ をするのはこちら

操作説明書にも、DJ コントローラーと組み合わせて DJ をする人は PERFORMANCE モードの章を読むように書かれています。EXPORT モードの使い道は後のレッスン「クラブの機材で DJ する」で扱います。

  1. rekordbox を起動し、FLX4 をつないでおく
  2. 画面左上のモード切り替えで、PERFORMANCE を選ぶ（EXPORT が選ばれているときは、そこから PERFORMANCE に変える）
  3. デッキと波形の画面に変わったことを確かめる
使える機能は契約プランと機材で変わる

操作説明書には、ご契約のプランによって使えない機能があると書かれています。FLX4 をつなぐと、サブスクリプション契約がなくても PERFORMANCE モードの機能が使えます（Hardware Unlock）。ただし、表示は無料プランのままで、有料プランと同じになるわけではありません。たとえば MIX POINT LINK は、FLX4 をつないでも使えません。FLX4 で使える機能は「機材をつないでソフトを準備する」の Hardware Unlock の説明を見てください。

PERFORMANCE モードの画面の全体

PERFORMANCE モードの画面は、大きく 2 つに分かれます。1 つは演奏のためのプレーヤーパネル、もう 1 つは曲を選ぶためのブラウザーパネルです。プレーヤーパネルの中には、さらに小さなパネルが並んでいます。

どのパネルがどこに並ぶかは、後で説明するレイアウトの選び方で変わります。そこで、ここでは場所ではなく、パネルの名前と役割で整理します。最初に見るものは太字にしています。

操作説明書での呼び名何があるか使いどころ
グローバルセクションモードの切り替え、レイアウトの切り替え、各パネルの表示ボタン、環境設定を開くボタン、マスター出力の音量メーターなど画面の見た目を変える。音が出ているか、音量が大きすぎないかを見る
トラック情報パネル曲名、アーティスト名、BPM、キー、残り時間、全体波形、SYNC 関連のボタンいまどの曲が、どんなテンポとキーで、あとどれくらいで終わるかを知る
拡大波形表示パネル再生位置のまわりを拡大した波形。ビートグリッドの線、キューの印ミックスの最中に、拍の位置と曲の展開を見る
JOG パネル再生ボタン、BPM とテンポの値、テンポレンジ、マスターテンポ（MT）、クオンタイズ（Q）、SLIP など再生中のテンポの状態を確かめる
パフォーマンスパッドHOT CUE、PAD FX、BEAT JUMP などのモードごとに内容が変わるパッドの表示ホットキューが登録されているかを見る。使い方は後のレッスンで扱う
ミキサーパネルチャンネルレベルインジケーター、TRIM、EQ、ヘッドホンのモニター、チャンネルフェーダー、クロスフェーダーFLX4 のミキサー部の状態を画面で確かめる
エフェクトパネルBEAT FX の種類やオン・オフ、かける先のデッキの選択エフェクトを使うレッスンで見る
ヘッドホンパネルヘッドホンのモニター音量とバランス（MIX、LEVEL）FLX4 の同名のつまみに対応する
サンプラーデッキ、録音パネル、マイクパネル、MIX POINT パネルなどサンプラー、録音、マイク、曲どうしのつなぎ位置の機能最初は使わない。必要になったら「rekordbox の演奏機能」のレッスンで触れる
ブラウザーパネルコレクションやプレイリストの一覧と、曲のリスト次に流す曲を探して選ぶ
最初は 4 か所だけ見る

慣れるまでは、トラック情報パネル（曲の情報）、拡大波形（拍の位置）、ミキサーパネル（音量）、ブラウザーパネル（次の曲）の 4 か所だけで足ります。表示が多すぎると、ミックス中に必要な情報を探すのに時間がかかるためです。サンプラーや録音などは、必要になるまで閉じておいてかまいません。

デッキの表示を読む

デッキの情報は主にトラック情報パネルと JOG パネルにあります。1 台のデッキについて、次の表示が確認できます。

トラック情報パネル

表示分かること
トラック名、アーティスト名どの曲がロードされているか
BPM とキー（原曲のもの）曲が本来持っているテンポとキー。テンポスライダーで速さを変えても、ここは原曲の値のまま
残り時間・再生経過時間曲があと何分で終わるか。次の曲を用意するタイミングの目安になる
全体波形曲全体の形と、いまの再生位置、キューの印。クリックするとその位置に再生位置が移動する
BEAT SYNC と MASTERSYNC のオン・オフと、基準になるデッキ（シンクマスター）の指定
キーシンクと半音の上げ下げのボタン、現在のキーの表示キーを半音単位で動かせる。動かしたときは、原曲からの変更分が表示される。ダブルクリックでキーをリセットできる
x 1 / x 2 / x 1/2SYNC のとき、基準のテンポの 1 倍・2 倍・半分に合わせる切り替え（SYNC RATE）。環境設定で表示のオン・オフができる

JOG パネル

表示分かること
現在の BPMテンポを変えたあとの、いまの BPM
テンポの割合（％）原曲から何 % 速く（遅く）なっているか。ダブルクリックで 0% に戻せる
テンポレンジテンポを動かせる幅。クリックするたびに切り替わる（±6、±10、±16、WIDE）。FLX4 の SHIFT + BEAT SYNC と同じ幅の選択肢
MT（マスターテンポ）赤く点灯しているとき、テンポを変えても音の高さ（キー）が変わらない。マスターテンポのオン・オフを示す
Q（クオンタイズ）クオンタイズのオン・オフ。キューやループの位置を拍に合わせる機能
SLIPスリップ機能のオン・オフ。ループなどの操作をしても、裏で元の再生が進み続ける機能

テンポスライダーを動かしたとき、トラック情報パネルの BPM は原曲の値のまま、JOG パネルの BPM と割合（％）だけが変わります。「原曲の値」と「いまの値」を別々に見られるのが便利な点です。マスターテンポをオフにして SYNC などでテンポが変わると、キーの表示も一緒に変わります。

FLX4 側でテンポの幅を変える方法は「拍・小節・BPM」で、ビートグリッドや解析は、のちの「曲を取り込んで解析する」で扱っています。

波形の見かた

波形は 2 種類あります。役割が違うので、使い分けて見ます。

種類場所見えるもの何に使うか
全体波形トラック情報パネル曲の最初から最後まで。キューポイント、メモリーキュー、ホットキューの印。フレーズの表示（環境設定でオンにしたとき）曲の構成と、いまどのあたりを再生しているかを一目で知る。クリックでその位置へ移動できる
拡大波形拡大波形表示パネル再生位置のまわりを拡大した波形。ビートグリッドの線拍の位置を見ながらミックスする。ズーム倍率を変えられる

「曲の構成とフレーズ」で学んだ、波形の太さで曲の展開を読む方法は、全体波形でそのまま使えます。波形が細くなっているところがブレイクやイントロ、アウトロで、太く詰まっているところがメインやドロップです。曲を再生する前に全体波形を見れば、どこで次の曲に入るかの見当がつきます。

拡大波形のビートグリッド

拡大波形には、解析で見つかった拍の位置が、白い線（ビートグリッド）で表示されます。4 拍ごとに、小節の頭の拍（1 拍目）が赤い線になります。いま再生している位置は、波形の中央の縦線です。直し方は「曲を取り込んで解析する」で扱います。

  • 白い線が拍の位置（ビートグリッド）、4 拍ごとの赤い線が小節の頭、中央の縦線が再生位置
  • ドラムの「ドン」という音の山が、白い線にぴたりと重なっていれば、解析は合っている
  • 山と線がずれていたら、グリッドのずれ。直し方は「曲を取り込んで解析する」で扱う

キューの印も波形の上に出ます。メモリーキューやホットキューを設定すると、その位置が全体波形と拡大波形に表示されます。設定のしかたは「CUE を打つ」で練習します。

FLX4 から波形を操作する

FLX4 の ロータリーセレクターを SHIFT を押しながら回すと、拡大波形が拡大・縮小します。右に回すと拡大、左に回すと縮小します。波形を細かく見たいときと、先の展開まで見渡したいときで、使い分けます。

波形の色は変えられる

波形の色は環境設定の表示カテゴリーのカラータブで選べます。この画面や本文の説明と色が違って見えても、読み方は同じです。詳しくは「rekordbox の設定を整える」で扱います。

テンポスライダーで曲を速くしました。トラック情報パネルの BPM と、JOG パネルの BPM は、それぞれどうなる？

  • どちらも速くした値に変わる
  • トラック情報パネルは原曲の値のまま、JOG パネルは変えたあとの値になる
  • どちらも原曲の値のまま、割合（％）だけが変わる

トラック情報パネルの BPM とキーは原曲のものです。JOG パネルにはテンポを動かしたあとの BPM と、原曲からの割合（％）が表示されます。

ブラウザーパネル：曲を探して読み込む

ブラウザーパネルは次に流す曲を探して選ぶところです。左側の一覧（ツリービュー）で見たい場所を選ぶと、その中の曲が右側のトラックリストに並びます。

場所何があるか使いどころ
コレクションrekordbox に取り込んだ、すべての曲曲を探す元になる一覧。「曲を取り込んで解析する」で曲を入れる場所
プレイリストDJ プレイの用途に合わせて作った、曲のまとまり練習用、当日用などに分けておくと、探す手間が減る
そのほか（関連するトラック、演奏履歴、エクスプローラなど）いまロードしている曲に関係する曲、過去に再生した履歴など慣れてから使う
トラックリスト選んだ場所の曲の一覧。曲名、BPM、キーなどの列があるBPM やキーを見て、いまの曲につなげやすい曲を選ぶ

トラックリストの列は列の見出しを右クリックして、表示するものを選べます。ドラッグで並び順も変えられます。曲が増えてくると、BPM とキーの列を見て選曲することになるので、見やすい並びにしておくと便利です。キーの表示のしかたは次のレッスンで扱います。曲の探し方や整理は、のちの「曲を整理して探す」で詳しく説明します。

FLX4 で曲を選んで、デッキに読み込む

マウスで曲をデッキにドラッグ＆ドロップして読み込むこともできますが、DJ 中は FLX4 の操作で読み込みます。ミックス中に手をミキサーから離してマウスに伸ばすと、ほかの操作が遅れるからです。

  1. ロータリーセレクターを回して、トラックリストの曲にカーソルを合わせる
  2. ロードしたいデッキの LOAD を押す（左のデッキなら左の LOAD）
  3. 画面のデッキに曲名や波形が表示されたら、読み込み完了

ロータリーセレクターを押すと、カーソルが左の一覧（ツリービュー）とトラックリストの間を行き来します。先にコレクションやプレイリストを選び、続けて曲を選ぶ、という流れで使えます。

LOAD のほかの動き

LOAD を 2 回押すと、反対側のデッキの曲が、押した側のデッキにも読み込まれます。再生中なら同じ位置から再生されます（インスタントダブルス）。SHIFT を押しながらデッキ 2 の LOAD を押すと、デッキの表示が小さくなってブラウザーが広く表示され、もう一度押すと戻ります。

レイアウトを切り替える

画面の並べ方はグローバルセクションか、画面上部の表示メニューから切り替えられます。デッキの数、拡大波形の向き、ブラウザー領域の広さを選べます。

レイアウト特徴
2Deck Horizontal（2 デッキ・横波形）拡大波形が横向きに並ぶ。このコースの説明はこの形を想定している
2Deck Vertical（2 デッキ・縦波形）拡大波形が縦向きに並ぶ
4Deck Horizontal / 4Deck Vertical4 つのデッキを使うとき
ブラウズブラウザーパネルが広がる。曲を選ぶのに便利

プランによっては、レイアウトの選択が制限されることがあります。切り替えられないときは、そのとき表示されているレイアウトのまま進めてかまいません。

FLX4 は 2 チャンネルのコントローラーなので、初心者は 2 デッキの横波形で十分です。曲を選ぶときだけ、ブラウズに切り替えると見やすくなります。4 デッキは DJ プレーヤーなどを追加して 4 台を操作するときの設定です。

FLX4 をつないで DJ をするとき、画面左上で選ぶのはどれ？

  • EXPORT
  • PERFORMANCE
  • どちらでも同じ画面になる

EXPORT モードは曲を DJ プレーヤー向けに書き出す準備のモードです。パソコンの中の曲を FLX4 で再生してミックスするのは PERFORMANCE モードです。

拡大波形で、白い線と、4 拍ごとの赤い線は何を表している？

  • 白い線がキューポイント、赤い線が曲の終わり
  • 白い線が拍の位置（ビートグリッド）、赤い線が小節の頭（1 拍目）
  • 赤い線が低音、白い線が高音

白い線は解析で見つかった拍の位置（ビートグリッド）で、そのうち小節の頭の拍が 4 拍ごとに赤い線で表示されます。いま再生している位置は中央の縦線です。ドラムの音の山がこの線に重なっているかどうかで、解析が合っているかを確かめられます。

FLX4 でトラックリストの曲を、左のデッキに読み込むときの操作はどれ？

  • PLAY/PAUSE を押してから、ロータリーセレクターを回す
  • ロータリーセレクターで曲を選び、左のデッキの LOAD を押す
  • クロスフェーダーを左いっぱいに動かす

曲を選ぶのはロータリーセレクター、読み込むのは LOAD です。LOAD は読み込みたいデッキ側のものを押します。

まとめ

  • FLX4 で DJ をするのは PERFORMANCE モード。EXPORT は DJ プレーヤー向けに曲を書き出す準備のモード
  • 最初に見るのは、トラック情報パネル、拡大波形、ミキサーパネル、ブラウザーパネル
  • トラック情報パネルの BPM とキーは原曲の値。テンポを変えたあとの値は JOG パネルで見る
  • 全体波形で曲の構成、拡大波形でビートグリッド（拍は白い線、小節の頭は赤い線）と再生位置（中央の縦線）を見る
  • 曲はロータリーセレクターで選んで、LOAD で読み込む
  • レイアウトは 2 デッキの横波形でよい。曲を選ぶときだけブラウズに切り替えると見やすい
