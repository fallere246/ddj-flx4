DJ はなにをしているのか

DJ は曲を選び、曲と曲を途切れずにつなぎ、その場の雰囲気をつくる人です。このレッスンでは DJ の仕事の中身と、DDJ-FLX4 のようなコントローラーで DJ をするしくみを見渡します。最後に、2 曲を重ねるとどうなるかを実際に聴いて、このコースで身につけることの全体像をつかみましょう。

このレッスンでできるようになること

  • DJ の仕事を、自分の言葉で説明できる
  • コントローラー DJ で、曲・DJ ソフト・FLX4 がそれぞれ何をしているかが分かる
  • 音がデッキからスピーカーまで、どの順に流れるかが分かる
  • 2 曲をつなぐために必要な 3 つの技術と、このコースの進め方が分かる

DJ の仕事

DJ（ディスクジョッキー）の仕事は、大きく 3 つに分けられます。

  • 曲を選ぶ：その場にいる人や時間帯に合う曲を選ぶ
  • 曲をつなぐ：曲と曲を、音が途切れたり、リズムがぶつかったりしないように切り替える
  • 雰囲気をつくる：曲の盛り上がり（エネルギー）を上げたり下げたりして、時間の流れをつくる

DJ 自身は曲をつくっていなくても、「どの曲を、どの順で、どうつなぐか」で自分らしさを表現できます。同じ曲を使っても、つなぎ方や順番が違えば、まったく違う時間になります。これが DJ の面白さです。

曲を選ぶ力（選曲）と、曲をつなぐ力（技術）は別のものです。このコースでは、まずつなぐ技術を基本として身につけ、そのうえで選曲やセットの組み立てを学びます。つなぎが不安定だと、せっかく選んだ曲の良さも伝わらないからです。

DJ がいる場面

DJ はさまざまな場所で活躍しています。場面によって、求められることが少しずつ違います。

場面求められること（目安）
クラブ踊る人が止まらないように、途切れないつなぎと、時間をかけた盛り上げ
バー・ラウンジ会話のじゃまをしない音量と選曲。空間になじむ雰囲気づくり
パーティー・イベント幅広い人が知っている曲や、会場の目的に合った曲を、その場の反応を見ながら選ぶ
配信画面の向こうの視聴者に向けた、聴きやすい音量とつなぎ。トークも大事になることがある
家での練習失敗しても大丈夫。自分の好きな曲で、つなぎ方を試して身につける

どの場面でも基本になるのは、曲を気持ちよくつなぐ技術です。このコースは家で練習する人を想定して進みます。

DJ 機材の基本形

DJ 機材の基本形は2 台のプレーヤー（デッキ）と、それをつなぐミキサーです。1 台目で流している曲の横で、2 台目に次の曲を準備し、ミキサーで音量を切り替えます。2 台あることで、曲を途切れさせずに入れ替えられます。

昔は、レコードを回すターンテーブルや、CD プレーヤーが使われました。今は、PC に入れた曲を DJ ソフトで再生し、コントローラーで操作するスタイルも一般的です。DDJ-FLX4 もこのコントローラーの 1 つで、2 つのデッキとミキサーの形をしています。

コントローラー DJ のしくみ

FLX4 を使った DJ では、役割が次のように分かれています。

もの役割
曲のデータPC（やスマホ）の中に入っている
DJ ソフト（rekordbox / Serato DJ Lite）曲を再生し、テンポや音量を処理する。実際に音をつくっているのはソフト
FLX4ソフトを手で操作するための機材。あわせて、ヘッドホンやスピーカーに音を送る出口（オーディオインターフェース）も兼ねる

FLX4 のボタンやつまみを動かすと、その動きがソフトに伝わり、ソフトが音を変えます。そのため、ソフトを起動していない FLX4 だけでは、曲は再生できません。反対に、ソフトだけでもマウスで操作はできますが、2 本の手で同時に細かく操作するには、コントローラーのほうが向いています。

FLX4 で使えるソフト

FLX4 では、rekordbox（Mac/Windows、iOS/Android）と Serato DJ Lite が使えます。このコースは rekordbox（Mac/Windows）を前提に説明します。ほかのソフトを使うときは、ページの上部にある切り替えで、使うソフトを選んでください。ソフトによって違う内容は、選んだソフトの内容に切り替わります。ソフトの準備は「機材をつないでソフトを準備する」で説明します。

音の流れ

DJ は、音がどの順番で流れるかを頭に入れておくと、どのつまみが何をするのかが分かりやすくなります。まず全体の流れを図で見てみましょう。

順に説明します。

  1. デッキ：曲を再生する。デッキ 1 とデッキ 2 の 2 つがある
  2. TRIM：曲ごとの音量の差をそろえる、入口の音量つまみ
  3. EQ：低音・中音・高音の量を調整する
  4. CFX：つまみ 1 つで音色を変えるエフェクト（フィルターなど）
  5. チャンネルフェーダー：そのチャンネルの音を、どれだけ出すか
  6. クロスフェーダー：2 つのチャンネルの出し入れを、1 本で切り替える
  7. マスター：全体の音量（MASTER LEVEL）を決めて、スピーカーに送る

ヘッドホンにはスピーカーとは別の音を送れます。CUE を押したチャンネルの音と、マスターの音が届きます。これを使うと、お客さんには聞こえない状態で、次にかける曲を聴いて準備できます。くわしくは「ヘッドホンで次の曲を聴く」で学びます。

それぞれの部品の使い方はこれから 1 つずつ学びます。いまは「音は上から下へ流れ、途中で音量や音色が変えられる」ことだけ覚えておけば十分です。

FLX4 だけをパソコンにつながずに電源を入れて、曲を再生できますか？

  • できる。FLX4 の中に曲が入っている
  • できない。曲を再生するのは DJ ソフトで、FLX4 はそれを操作する機材
  • できる。ただし音はヘッドホンからしか出ない

曲のデータは PC（やスマホ）にあり、再生や音の処理は DJ ソフトが行います。FLX4 はソフトを手で操作するための機材で、音の出口も兼ねています。

2 曲を「つなぐ」とは

DJ のいちばん大事な仕事は曲と曲をつなぐことです。1 曲目の終わりと 2 曲目の始まりを重ねて、少しずつ入れ替えます。この入れ替えをトランジション（つなぎ）といいます。ただ重ねるだけだと、リズムがずれたり、低音がぶつかったりして濁ってしまいます。きれいにつなぐには、次の 3 つの技術が必要です。

技術やること学ぶレッスン
1. テンポをそろえる2 曲の BPM（テンポ）を同じにして、キックを重ねる「拍・小節・BPM」、「テンポを合わせる」
2. タイミングをそろえる曲の区切り（フレーズ）の頭で、次の曲を入れる「曲の構成とフレーズ」、「フレーズの頭でつなぐ」
3. 音量と EQ で混ぜるフェーダーと EQ で、2 曲の音量と低音のバランスを取りながら入れ替える「音の基本」、「はじめてのミックス」

体験：SYNC を使わないとどうなるか

まず、テンポがそろっていないとどう聞こえるかを体験します。下のツールは 2 つのデッキとミキサーのしくみを簡単に再現したものです。DECK 1 には Sunrise Drive（124 BPM）、DECK 2 には Night Signal（127 BPM）が入っています。DECK 2 のフェーダーは最初から上がっています。

  1. DECK 1 と DECK 2 の PLAY を、続けて押して、両方を再生する（テンポが違うままの音を聴くため、SYNC は押さない）
  2. 数十秒聴く。最初は重なって聞こえたキックが、だんだん「ドドッ」とずれていく
  3. DECK 2 の BEAT SYNC を押す。DECK 2 のテンポが DECK 1 に合い、キックがそろう

BPM が 3 違うだけで、数秒聴くとキックが大きくずれます。これが「テンポをそろえる」ことが必要な理由です。そろえる方法には手でテンポを調整する方法と、BEAT SYNC でソフトにまかせる方法があります。ただし、SYNC はテンポをそろえるだけです。どこから次の曲を入れるか（フレーズ）や、音量・EQ の調整は、DJ 自身が行います。

ツールは仕組みを耳で理解するためのもの

このサイトのツールは、FLX4 の代わりではなく、仕組みを理解するための練習台です。それぞれの内容のあとで、FLX4 での操作を説明します。

このコースの進め方

コースは 4 つの部に分かれています。ページの左にあるコース一覧で、いまどこにいるかが分かります。

  1. DJ の前提知識：DJ の仕事、リズム、曲の構成、音、キー、曲の入手。機材がなくても進められる。つなぎの練習は、この知識が前提になるため先に学ぶ
  2. 準備する：FLX4 をつなぎ、ソフトに曲を取り込んで解析し、CUE を打つ
  3. つなぐ：ヘッドホンで次の曲を準備し、テンポとフレーズをそろえて、2 曲をつなぐ
  4. 表現を広げる：ループ、エフェクト、パッド、選曲とセットの組み立て、練習のしかた
  • 練習ツール：レッスン中に出てくる、音の出るツール。ブラウザで動くので、機材がなくても練習できる
  • ソフトの切り替え：ページ上部のボタンで、使うソフトを選ぶ。選んだソフトに合わせて説明が変わる
  • 本体マニュアル：黒いボタン風の部品名（PLAY/PAUSE のようなもの）をクリックすると、FLX4 の各部の説明が開く。本体マニュアルのページから直接見ることもできる
  • 完了ボタン：レッスンの最後にある。読み終えたら押すと、進み具合が記録される

分からない言葉が出てきたら、用語集で確かめられます。機材がうまく動かないときは、困ったときを見てください。

2 曲をきれいにつなぐために必要な 3 つの技術として、正しい組み合わせはどれ？

  • 曲を速く切り替える・音量を最大にする・エフェクトをかける
  • テンポをそろえる・音の高さをそろえる・曲名をそろえる
  • テンポをそろえる・フレーズの頭でタイミングをそろえる・音量と EQ で混ぜる

テンポ（BPM）、タイミング（フレーズ）、音量と EQ の 3 つです。エフェクトは慣れてから加える味付けで、つなぎの基本ではありません。

まとめ

  • DJ の仕事は曲を選び、つなぎ、雰囲気をつくること
  • 機材の基本形は 2 台のデッキとミキサー。コントローラーと DJ ソフトの組み合わせも一般的
  • FLX4 は DJ ソフトを操作する機材で、音の出口も兼ねる。ソフトがないと曲は再生できない
  • 音はデッキ → TRIM → EQ → CFX → チャンネルフェーダー → クロスフェーダー → マスター → スピーカーの順に流れる
  • つなぎに必要なのは、テンポ、タイミング（フレーズ）、音量と EQ の 3 つ
